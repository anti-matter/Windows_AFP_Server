Installation
------------
To install, just run the installer and allow for administrative priveleges. To launch, click the new "Personal AFP Server" icon on your desktop.


To Uninstall
------------
Just run the installer again, or use the Program Files control panel.


To Configure
------------
To configure the server, click the server's icon on the Windows tray. A configuration window will appear where you can create shares, control access, etc.
